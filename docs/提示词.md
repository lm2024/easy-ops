#### 1. 项目无jarName配置时监控失效

问题描述：当项目没有配置jarName时，getExpectedJarName()返回null，导致findProcessByJarName()返回null，进程状态永远显示为STOPPED，即使应用正在运行。

// ... 其余逻辑 ...
}

// 方案2：fallback到第一个匹配的进程

// 如果jarName匹配失败，尝试匹配项目名

问题位置：NodeController.saveOneSnapshot()

影响：前端显示"进程已停止"但CPU使用率不为0，数据矛盾。
修复建议：

// 在markStopped()中清除所有进程相关指标

snap.setProcessPid(null);

snap.setMemoryMb(null);        // 清除进程内存
snap.setHeapUsedMb(null);      // 清除堆内存
snap.setHeapMaxMb(null);
snap.setGcCount(null);
snap.setGcTimeMs(null);
}
